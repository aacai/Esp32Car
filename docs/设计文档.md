# ESP32-C3 小车网页遥控 — 设计风格指南

## 整体风格：iOS 磨砂玻璃（Glassmorphism）

网页采用深色为主的 **iOS 风格磨砂玻璃** 设计，背景为多彩光斑 + 半透明卡片，卡片通过 `backdrop-filter` 模糊底层色彩，呈现通透的玻璃质感。

### 背景光斑

四团柔和径向渐变光斑（蓝 / 青 / 紫 / 粉），使用 `body::before` 固定层实现，`z-index: -1` 置于内容下方。卡片通过 `backdrop-filter: blur(22px) saturate(160%)` 模糊这些光斑，形成 iOS 磨砂效果。

### 卡片（`.card`）

- 圆角 `24px`
- 模糊 `blur(22px) saturate(160%)`
- 半透明填充 `var(--card)`
- 边框 `1px solid var(--card-brd)`
- 双层阴影：外阴影 `0 8px 32px rgba(0,0,0,.30)` + 内高光 `inset 0 1px 0 rgba(255,255,255,.14)`

### 分段控件（`.mode-switch`）

iOS 风格胶囊容器：
- 容器：`padding: 4px`，`background: rgba(0,0,0,.18)`，圆角 `14px`
- 按钮：无边框、透明背景、透明文字
- 活动态：`background: var(--seg-active)` + 底部投影 + 内高光

### 滑块（`input[type="range"]`）

- 轨道：高 `8px`，圆角胶囊
- 拇指：`26px` 圆，白色 + 双层阴影（下方投影 + 顶部柔光环）

### 方向键（`.pad-btn`）

- 圆角 `20px`
- 玻璃渐变背景 `linear-gradient(180deg, rgba(255,255,255,.10), rgba(255,255,255,.03))`
- 内高光 + 底部柔和阴影
- 按下时缩放 `.93` +  accent 色填充

### 字体

`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif` — 优先系统字体，iOS 上呈现 San Francisco 风格。

### 主题切换

顶部栏语言 / 主题按钮，三套主题循环切换：深色 → 浅色 → 粉色。所有色彩通过 CSS 变量驱动，切换无闪烁。

### 响应式

- 最大宽度 `460px`，居中
- 方向键格子 `64px`（小屏）/ `76px`（常规）
- 横屏手机限制高度
- 触摸目标最小 `44px`

### 动画（遵循 WCAG 与 Apple HIG）

| 动画 | 触发 | 时长 | 方式 | 说明 |
|------|------|------|------|------|
| 卡片入场 | 页面加载 | `.45s` | `ease both` | 四张卡片依次延迟 `.04s`  staggered 出现，`translateY(18px)` → 归位 |
| 连接呼吸 | BLE/WiFi 连接 | `2.4s` 循环 | `ease-in-out infinite` | 绿色状态点柔和脉动，传达"在线" |
| 卡片悬停 | 鼠标悬停 | `.2s` | `ease` | 卡片上浮 `2px` + 阴影加深 |
| 进度条 | OTA 上传中 | `.2s` | `ease` | 已有，平滑填充 |
| 加载旋钮 | OTA 上传中 | `.6s` 循环 | `linear infinite` | 按钮内旋转圆环，替代文字"上传中…" |
| 状态消息 | OTA 成功/失败 | `.3s` | `ease both` | 滑入出现 |

所有动画遵守 `prefers-reduced-motion`：该媒体查询下 `animation` 和 `transition` 均被禁用，卡片直接可见，状态点静态显示。
