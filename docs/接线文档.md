# ESP32-C3 SuperMini + L298N 小车硬件接线指南

> 本文档针对 **ESP32-C3 SuperMini** 这款小板子编写，代码中的引脚已按 SuperMini 可用的 GPIO 适配。

---

## 所需材料

| 物料 | 数量 | 说明 |
|------|------|------|
| **ESP32-C3 SuperMini** | 1 块 | 超小 RISC-V 开发板，USB-C |
| **L298N 电机驱动模块** | 1 个 | 双 H 桥，可驱动两路直流电机 |
| **直流减速电机** | 4 个 | 4WD 底盘用（建议 6V~12V） |
| **12V 锂电池组** | 1 组 | 3S 锂电（11.1V~12.6V），给 L298N 供电 |
| **5V 降压模块**（强烈建议） | 1 个 | LM2596 或 Mini560，12V→5V 给 ESP 供电 |
| 杜邦线（公对母/公对公） | 1 把（约 20 根） | **仅用于 ESP↔L298N 信号线**（电流很小） |
| 硅胶线（矽线）18~22AWG | 红黑各 1~2 米 | **L298N↔电机、电池↔驱动** 的大电流线 |
| XT60 / DC 插头（可选） | 若干 | 电池与大电流线的可靠连接 |
| USB-C 数据线 | 1 条 | 烧录和调试 |

## 电源方案（非常重要 ⚠️）

L298N + 4 个电机启动电流可达 **2~4A**，**绝对不能**从 ESP 的 3.3V 取电！

```
┌──────────────────────────────────┐
│         12V 锂电池 (3S)           │  11.1V ~ 12.6V
│        +                  -       │
│         │                │        │
│         ├── L298N 12V ───┤        │  ← 电机主电源
│         │                │        │
│         └── LM2596 ──────┘        │  ← 5V 给 ESP
│              │                    │
│              ▼ 5V                 │
│         ESP32-C3 SuperMini        │
│          丝印 5V ◄───────────┘
└──────────────────────────────────┘
```

### 💡 没有 LM2596 降压模块，行不行？

**不必须，但 ESP 落地跑一定要吃电池的电。** 降压模块只是给 ESP 供 5V「最稳」的方案。

> ⚠️ USB 供电只适合「插在电脑上调试 / 烧录」的阶段——小车真要落地满地跑，MCU 当然得从电池取电，不能拖着 USB 线。

落地运行时，ESP 的 5V 要从 12V 电池来，有两条路：

- **路 1：蹭 L298N 板载的 5V（免模块，从电池来）**
  L298N 吃 12V 电池，板上的稳压器会转出 5V 出现在 `5V` 排针上；引一根线到 ESP 的丝印 `5V` 即可。**注意保留 L298N 上的「5V 使能」跳帽**，否则板载 5V 不出。
  ⚠️ 板载稳压器压差大、余量小，ESP 跑蓝牙时电流一高可能**掉压重启**，所以文档标「不推荐」；但它是没有降压模块时唯一「从电池供电、免额外模块」的出路，可以先试。
- **路 2：外加降压模块（LM2596 / Mini560，最稳）**
  从电池 12V 转出 5V 给 ESP，带载能力远超板载稳压器，蓝牙小车首选。

> 一句话：**不想买模块就用 L298N 板载 5V 给 ESP（从电池来，落地能跑，可能偶发重启）；要稳就加块 LM2596。**

### ⭐ 推荐方案：LM2596 降压给 ESP

这是最稳的，一块 LM2596 模块不到 5 块钱：

```
12V 电池正极 ──┬── L298N  12V 端子
               │
               └── LM2596 IN+
                    LM2596 IN- ── 电池负极 ── L298N GND ── ESP GND
                    LM2596 OUT+ ── ESP32 SuperMini 丝印 5V
```

**注意**：LM2596 输出要**先调好电压再接到 ESP**——用万用表测 OUTPUT 端，调螺丝到 **5.0V** 再接线。

### 备选方案 A：USB 供电（调试阶段用）

- **ESP32-C3 SuperMini**：直接插 USB-C 供电
- **L298N + 电机**：12V 电池单独供电
- **必须共地**：L298N GND ── ESP 的丝印 GND

### 备选方案 B：L298N 板载 5V 给 ESP（不推荐）

- L298N 的 5V 输出端子 → ESP SuperMini 丝印 5V
- **风险**：L298N 板载稳压器只有 **100mA**，ESP32-C3 跑 WiFi/BLE 时瞬间电流能到 200mA+，会掉压重启
- **仅适合纯调试，不够可靠**

> **💡 核心铁律：所有 GND 全部连通！** 否则控制信号电平不共地，电机乱转/不转。
> **💡 绝对不要用 ESP 的 3.3V 给 L298N 逻辑供电！**

## ⚠️ ESP32-C3 SuperMini 引脚警告（必读）

SuperMini 有些引脚有**启动约束（Strapping）**，接线前务必了解：

| GPIO | 风险 | 说明 |
|------|------|------|
| GPIO 2 | ⚡ 启动脚 | 上电**必须为高电平**（代码初始化很快，影响不大） |
| GPIO 8 | ⚡ 启动脚 + 板载蓝灯 | 上电**必须为高电平**；低电平焊盘接 LED |
| GPIO 9 | ⚡ 启动脚 + BOOT 键 | 低电平=下载模式，正常应悬空或高电平 |
| GPIO 4~7 | 🛠 JTAG 脚 | 默认未启用 JTAG，当普通 IO 用没问题 |
| GPIO 21/20 | 📡 串口 | 用于 USB 烧录/日志，**建议不要占用** |

**代码中已避开风险引脚**，你按接线图直接接即可。

## GPIO 引脚分配（代码已配好）

| 板子丝印（直接看板边印的数字） | 实际就是 | 接 L298N 端子 | 功能 |
|-------------------------------|----------|---------------|------|
| `1` | GPIO 1 | **IN1** | 左侧电机方向 A |
| `2` | GPIO 2 ⚡(启动脚) | **ENA** ⚡ | 左侧电机 PWM 调速 |
| `3` | GPIO 3 | **IN2** | 左侧电机方向 B |
| `4` | GPIO 4 | **IN3** | 右侧电机方向 A |
| `5` | GPIO 5 | **IN4** | 右侧电机方向 B |
| `10` | GPIO 10 | **ENB** | 右侧电机 PWM 调速 |
| `GND` | — | **GND** | **共地，必须接！** |
| `5V` | — | **5V** | ESP 电源输入（来自 LM2596 / USB） |

> **板子边上印的数字 `0~10 / 20 / 21` 就是 GPIO 编号本身**，照着数字接即可，不存在另外的「引脚 1~16」或「A1/IO1」编号。
> 其中 `A0~A5` 只是 ADC 通道别名（GPIO0~GPIO5），和丝印数字指向同一个脚，不用另找「An」焊盘。
> `IN1/IN2` 控制左电机正反转，`IN3/IN4` 控制右电机正反转，`ENA/ENB` 控制速度。

> ⚠️ **为什么不能只接 1/2/3/4 四个脚？** 电机一共要 **6 路信号**（IN1~IN4 四个方向 + ENA/ENB 两个调速），
> 4 个脚装不下。板子的 `1/2/3/4` 已用于 IN1/ENA/IN2/IN3，剩下的 IN4 只能再用 `5`、ENB 再用 `10`，
> 所以**必须额外占用丝印 `5` 和 `10`**，无法只靠 1/2/3/4。

## ESP32-C3 SuperMini 引脚定义图

```
             正面（USB-C 口朝向自己，长边在左右两侧）
   ┌────────────────────────────┬────────────────────────────┐
   │  左侧排针（丝印）            │  右侧排针（丝印）            │
   ├────────────────────────────┼────────────────────────────┤
   │  5V   → 电源输入 5V         │  5    → GPIO5  (A5) ◄ IN4   │
   │  GND  → 地（共地必接）      │  6    → GPIO6  (A6)         │
   │  3V3  → 3.3V 输出           │  7    → GPIO7  (A7)         │
   │  4    → GPIO4  (A4) ◄ IN3   │  8    → GPIO8  (板载蓝灯)   │
   │  3    → GPIO3  (A3) ◄ IN2   │  9    → GPIO9  (BOOT 键)    │
   │  2    → GPIO2  (A2) ⚡ ENA   │  10   → GPIO10      ◄ ENB   │
   │  1    → GPIO1  (A1) ◄ IN1   │  20   → GPIO20 (UART RX)    │
   │  0    → GPIO0  (A0)         │  21   → GPIO21 (UART TX)    │
   └────────────────────────────┴────────────────────────────┘

   ⚠️ 板子丝印的数字（0~10 / 20 / 21）就是 GPIO 编号本身；
      A0~A5 只是 ADC 通道别名，与丝印数字指向同一个脚，不是另一个焊盘。
```

> 如果拿不准哪侧是左/右：你板子上印着 `5V GND 3V3 4 3 2 1 0` 的那一排是「左侧」，
> 印着 `5 6 7 8 9 10 20 21` 的那一排是「右侧」——接线只看丝印数字，左右无所谓。

## 接线步骤

### 1. L298N → 四个电机

L298N 的两个输出通道各驱动一侧的 2 个电机（并联）。

**通道 A — 左侧两个电机（并联）**

```
L298N OUT1 ───── 左前电机 正极
L298N OUT2 ───── 左前电机 负极
                ───── 左后电机 正极（与前一个并联）
                ───── 左后电机 负极（与前一个并联）
```

**通道 B — 右侧两个电机（并联）**

```
L298N OUT3 ───── 右前电机 正极
L298N OUT4 ───── 右前电机 负极
                ───── 右后电机 正极（与前一个并联）
                ───── 右后电机 负极（与前一个并联）
```

> 并联方法：把左前左后 2 个电机的两根线分别拧到一起，再插到 L298N 端子。
> 试车时如果某个轮子方向反了，交换那一个电机的两根线即可。

> 💡 电机红黑线在壳体上的出线位置（一个在上、一个在下，或左右不对称）是随机 / 镜像安装的，**不影响电气连接**，只关系到走线好不好看。真正要确认的只有一件事：**四个轮子转动方向是否一致**（见下方「方向校准」）。

### 2. L298N → ESP32-C3 SuperMini

```
L298N端子        板子丝印（= GPIO）
─────────────────────────────────────
 IN1  ─────────  丝印 "1"    (= GPIO 1)
 IN2  ─────────  丝印 "3"    (= GPIO 3)
 IN3  ─────────  丝印 "4"    (= GPIO 4)
 IN4  ─────────  丝印 "5"    (= GPIO 5)
 ENA  ─────────  丝印 "2"    (= GPIO 2)  ⚡ 启动脚
 ENB  ─────────  丝印 "10"   (= GPIO 10)
 GND  ─────────  丝印 "GND"   ⭐ 必须接！（共地）
```

> **拔掉 L298N 上的 ENA/ENB 跳帽**（就是 IN1 旁、IN4 旁那两个黑色小塑料帽），否则 PWM 调速无效！

> ⚠️ **ENA/ENB 是 3 针排针，ESP 线必须接「EN 信号针」，不是 5V 针！**（这是最容易踩的坑）
> 拔掉跳帽后，ENA/ENB 那排针有 **3 根**：跳帽原本短接的是 **`5V` 针 与 `EN` 信号针** 这两根，第 3 根通常是空（NC）。
> - `5V 针`：板载稳压器出来的 5V，一直有电。**线插错到这里 = EN 信号针悬空 = 禁用 → 电机不转**。
> - `EN 信号针`：L298N 真正用来使能的脚，ESP 的 `丝印2` / `丝印10` 线要接**这里**才有效。
> - **识别方法**：把跳帽装回去，它只跨 2 根针，那 2 根就是「5V + EN」；ESP 线接到**其中不是 5V 的那一根**（通常是靠近板边、远离 5V 电源端子那一端）即可。
> - **验证口诀**：装回跳帽发 `F` 能转 = 硬件 OK；拔掉跳帽不转 = 线在 5V/NC 针上，挪到 EN 信号针即可。

### 3. L298N → 电源

```
12V 电池正极 ───── L298N  12V 端子
12V 电池负极 ───── L298N  GND 端子
```

### 4. ESP32-C3 → 电源

**推荐（LM2596 降压）**：

```
LM2596 OUT+ (5V) ──── SuperMini 丝印 5V
LM2596 OUT-        ──── SuperMini 丝印 GND
```

**调试阶段（USB 供电）**：

```
电脑 USB-C 线 ──── SuperMini USB-C 口
L298N  GND     ──── SuperMini 丝印 GND
```

## ⚠️ 用什么线：杜邦线 vs 电机线（必看）

这是新手最容易搞错的地方——**不是所有连接都能用杜邦线**。要不要杜邦线，取决于那根线上跑多大电流：

| 连接位置 | 走的电流 | 用什么线 | 能不能用杜邦线 |
|----------|----------|----------|----------------|
| ESP → L298N 的 **IN1/IN2/IN3/IN4 / ENA / ENB** | 几乎为 0（信号，< 10mA） | **杜邦线**（公对母最佳） | ✅ 可以 |
| ESP → L298N 的 **5V / GND** | 很小（ESP 逻辑电流，几十 mA） | **杜邦线** | ✅ 可以 |
| 电池 → L298N **12V / GND** | **大**（2~4A 以上） | **硅胶线 16~18AWG** + XT60/DC 插头 | ❌ 不可以 |
| L298N **OUT1~OUT4 → 电机** | **大**（每个电机堵转 1~2A，一侧两电机并联≈2~4A） | **硅胶线 18~22AWG** | ❌ 不可以 |
| 电池 → LM2596 输入 | 大（≈ ESP 电流） | **硅胶线 18~20AWG** | ❌ 不可以 |

### 为什么电机线不能用细杜邦线？

- 普通杜邦线大多是 **22~28 AWG 细线**，额定电流只有 **约 1A**，而且靠弹簧片接触，大电流下会：
  - **发热、熔化、甚至冒烟**；
  - 接触电阻大 → 电机**掉速、无力、时转时不转**；
  - 振动后容易松脱，造成电机突然停转。
- 一侧两个电机是**并联**的，L298N 一个通道实际要扛 2 个电机的电流，线必须更粗。

### 正确做法（不想用电烙铁也完全可以 ✅）

本项目的接线**全程可以免焊**，靠的是杜邦线和螺丝端子：

- **信号线（ESP ↔ L298N 的 IN1~4 / ENA / ENB / 5V / GND）**：全部用 **杜邦线（公对母）** 插在排针上，不用焊。
- **电源 / 电机线（电池、L298N 的 12V、OUT→电机）**：剥线后塞进 L298N 的 **螺丝端子** 拧紧即可，也不用焊。
- **电池端**：用免焊的 **子弹头/香蕉插头、XT60 压接插头、或带螺丝的电池夹**，别拿杜邦线直接夹电池——电池瞬间电流很大，杜邦头会打火烧融。

> 电机线一端塞进 L298N 的 OUT 螺丝端子（免焊拧紧）；另一端接电机端子：电机若是裸露金属片/引脚，可用 **冷压端子（插簧 / U 形）压接**在硅胶线上再插上（免焊），或用电烙铁焊。热熔胶只负责把接头固定在电机壳上防拉扯，**不能**代替导电连接。

### 热熔胶能干什么 / 不能干什么

- ❌ **不能代替焊锡做电气连接**：热熔胶**不导电**，把两根线"粘"在一起线是碰不到一起的，不会导通，电机不转。
- ✅ **只做固定和绝缘**：杜邦头插紧后点一点胶防松脱；把 ESP / L298N / 降压模块粘在底盘上；线材走线整理防短路；电机线从端子拉出处点胶防拉扯。
- ⚠️ 别用热熔胶糊住 **L298N 芯片和散热片**——它工作时发热需要散热；也别让胶把本该连通的相邻排针撑开或短路。

### 电机端子怎么焊（想用电烙铁也完全没问题）

焊锡**不是滴上去、也不是用烙铁粘着锡去点**，正确手法是「**先加热工件，再把锡喂到工件上，让工件把锡吸住**」：

1. **准备**：电烙铁预热到约 320~350°C；焊锡丝选 **含松香芯** 的（0.8~1.0mm，新手用有铅 Sn63/Pb37 熔点更低更好焊）；烙铁架 + 清洁海绵/黄铜棉。
2. **处理金属面**：电机端子若有氧化/油污，用砂纸或小刀轻轻刮到**露出金属光泽**；硅胶线剥出约 5~8mm 铜丝，绞紧。
3. **给烙铁"吃锡"**：烙铁头在海绵上擦干净，碰一点焊锡让它挂一层薄锡（导热更好、不氧化）。
4. **同时加热两个工件**：一手拿烙铁，让烙铁头**同时压住电机端子和导线铜丝**，加热 1~2 秒（原因：焊锡要"润湿"金属表面才能连牢，凉的工件会让锡瞬间凝固、只搭在表面形成虚焊，所以端子+线必须一起热到锡能同时裹住两边）。
5. **喂锡到工件**（关键）：另一手把焊锡丝送到「烙铁头与工件接触的位置」（也就是端子+线的连接处），锡会被工件**熔化并吸上去**包裹连接点。
6. **收尾**：看到锡流畅铺满、形成光滑小山坡状，先移开焊锡丝，再移开烙铁；**别动**，等 2~3 秒自然冷却凝固。
7. **检查**：好焊点**光亮、光滑、像小山坡**；发暗、哑光、有尖刺 = 虚焊，要补焊。再用万用表蜂鸣档测通断、确认两线之间没有短路。
8. **固定**：焊好冷却后，套热缩管或点一点热熔胶把线**固定在电机壳上防拉扯**（胶只固定，不导电）。

> ⚠️ 电机是塑料壳，烙铁别烫到塑料；动作要快（一次 2~3 秒），别长时间烤同一个点。烙铁一定放支架上，别碰到线或桌面。

❌ **两种错误焊法（新手最容易犯）**：
- 把锡滴在烙铁头上，再拿烙铁去"点"端子 → 锡只是搭着，虚焊、易脱落。
- 把锡直接滴在端子上不加热工件 → 锡不润湿金属，一碰就掉。

> 💡 一句话总结：**细杜邦线只接信号（ESP↔L298N 的小针脚），粗硅胶线才接电机和电池（大电流）。**

## L298N 跳帽检查（什么是"跳帽"？）

**跳帽（jumper / shunt）** 就是套在两根排针上的那个 **黑色小塑料帽**（里面是两个金属簧片），把相邻两根针短接在一起。拔掉它，两根针就断开，可以分别接别的东西。

### ZX-040 板子上跳帽长什么样

标准 L298N（ZX-040，红色小板）上共有 **3 个跳帽**：

| 跳帽 | 在板上的位置 | 出厂常见状态 |
|------|--------------|--------------|
| **ENA** | 紧挨 `IN1` 排针旁，2~3 根针的小排，上面套一个黑帽 | 常**插着**（黑帽） |
| **ENB** | 紧挨 `IN4` 排针旁，同样一个小黑帽 | 常**插着**（黑帽） |
| **5V 使能** | 在 `12V` / `GND` / `5V` 电源端子附近，单独一个小黑帽 | 保留，别动 |

> 如果你看到 IN1 旁边、IN4 旁边各有个**黑色小塑料帽**，那它**就是** ENA/ENB 跳帽——很多人以为那是板子固定件，其实是可以拔下来的。

### 正确设置

| 跳帽位置 | 状态 | 原因 |
|----------|------|------|
| **ENA** | **拔掉 ✅** | GPIO 2 负责 PWM 调速，不能让它被短接到 5V |
| **ENB** | **拔掉 ✅** | GPIO 10 负责 PWM 调速，不能让它被短接到 5V |
| **5V 使能** | **保留 ⚡** | 板载 5V 稳压供电（即使不用也要保留） |

> 不拔 ENA/ENB 跳帽 → 电机永远全速，按键调速度没反应！（若只想先让车跑起来、不在乎调速，留着跳帽也完全可以：方向控制正常，只是速度固定最大，无任何损坏。）

### 万一你的板子上"没有" ENA/ENB 跳帽？

有些廉价 ZX-040 出厂时：
- **跳帽没装 / 运输掉了**：ENA/ENB 排针是空的两根针。→ 找一根杜邦线把那两根针短接（= 一直使能全速）；想用 PWM 调速，就把 ESP 的 GPIO2/GPIO10 接到 ENA/ENB 排针的**信号针**（中间那根）上，不再短接。
- **使能焊死版**：板子上根本没有排针，PCB 用细铜线把 ENA 永久连到 5V。→ 这种只能**全速**，PWM 调速无效。GPIO2/GPIO10 接了也没用；要调速只能换一块带跳帽的板子，或用电烙铁刮开焊点、重焊引线接 PWM。

> 即使没有跳帽 / 使能焊死，电机**照样能转**（全速），方向仍由 IN1~IN4 控制；只是没法调速度而已，不影响先跑起来。

## 通电前检查清单

- [ ] L298N 的 **ENA 和 ENB 跳帽已拔掉**（IN1 旁、IN4 旁那两个黑色小帽，否则 PWM 无效）
- [ ] 所有 GND 已连通（**共地，这是最常见的故障原因**）
- [ ] ESP 的 3.3V 没有接到 L298N（会烧坏 ESP！）
- [ ] 电机端子的螺丝拧紧了，没有短路
- [ ] 电池电压在 L298N 范围内（**6V~12V**，不要超过 12V）
- [ ] LM2596 输出已用万用表调好 **5.0V**
- [ ] 如果是 USB 供电烧录，先断开电池或关闭 L298N 电源

## 常见问题排查

### ❌ 电机不转（听到 L298N "b"一声但不动）

说明 IN 方向信号已到 L298N，问题在使能(ENA/ENB)。按可能性排查：

1. **ENA/ENB 线插错了排针脚（最常见）**：ENA/ENB 跳帽拔掉后，那排针有 3 根，跳帽原本短接的是「5V — EN」两根。ESP 的 `丝印2→ENA` / `丝印10→ENB` 线必须接到 **EN 信号针**（和 5V 相邻、跳帽另一端的那根），**不是 5V 针**。插到 5V 针上 = EN 信号针悬空 = 禁用 → IN 到了也不转。
   - **快速确诊**：把 ENA、ENB 跳帽**装回去**（强制 EN=5V 全速），发 `F`。**转了** → 硬件全 OK，把 ESP 线挪到 EN 信号针即可；**还不转** → 看下面几条。
2. 共地了吗？→ L298N GND 连 ESP GND（**必接**）
3. 电池够压吗？→ L298N 12V 端子电压需 **> 7V**，板载 5V 稳压器才出 5V 逻辑电（电源 LED 亮 ≠ 5V 逻辑电在）
4. GPIO 接对了吗？→ IN1=丝印1, IN2=丝印3, IN3=丝印4, IN4=丝印5, ENA=丝印2, ENB=丝印10
5. 固件真的在跑吗？→ 串口应打印 `motor driver ready`，发 `F` 时应打印 `forward 60%`

### ❌ 电机只转一个方向
- 检查 IN1/IN2 和 IN3/IN4 是否接反
- 检查代码引脚定义是否和实际接线一致

### ❌ 方向反过来
- 交换电机的两根线即可
- 或者交换 L298N 的 OUT1/OUT2

### ❌ ESP 反复重启
- 电源不稳：LM2596 输出电压调到 5.0V
- L298N 干扰：在 L298N 的 12V 和 GND 间加一个 **470μF 电解电容**
- 没有共地：检查 GND 连线

### ❌ 上电后 ESP 无法烧录或启动
- 检查 GPIO 9（BOOT 键）是否被拉低了
- 确保使用的 GPIO 上没有意外的低电平（特别是 GPIO 2、8、9）

## 电机方向参考表

| 指令 | IN1 | IN2 | IN3 | IN4 | 左侧电机 | 右侧电机 |
|------|-----|-----|-----|-----|----------|----------|
| F（前进） | 1 | 0 | 1 | 0 | 正转 | 正转 |
| B（后退） | 0 | 1 | 0 | 1 | 反转 | 反转 |
| L（左转） | 0 | 1 | 1 | 0 | 反转 | 正转 |
| R（右转） | 1 | 0 | 0 | 1 | 正转 | 反转 |
| S（停止） | 0 | 0 | 0 | 0 | 停止 | 停止 |

如果按上表接线但车轮方向与预期相反，交换该电机的两根线即可。

## 附录：代码中的引脚定义位置

如需调整引脚，改 `main/motor.c` 顶部这几行（也可在 `idf.py menuconfig` 的 `Car Configuration → Motor (L298N) GPIO` 里改）：

```c
#define CONFIG_MOTOR_IN1_GPIO  1   // 左电机 IN1
#define CONFIG_MOTOR_IN2_GPIO  3   // 左电机 IN2
#define CONFIG_MOTOR_IN3_GPIO  4   // 右电机 IN3
#define CONFIG_MOTOR_IN4_GPIO  5   // 右电机 IN4
#define CONFIG_MOTOR_ENA_GPIO  2   // 左电机 PWM  ⚠️ 禁止 18/19（USB D-/D+）
#define CONFIG_MOTOR_ENB_GPIO  10  // 右电机 PWM  ⚠️ 禁止 18/19（USB D-/D+）
```

改完后重新 `idf.py build && idf.py flash` 即可。
